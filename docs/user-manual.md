# 使用手册（大肥鱼之家）

## 首次开机
1. 设备连上 Wi-Fi（与原小爱相同方式配网，或官改固件的设置里配）。
2. 屏幕右上角 ⚙ → **设置管理密码**（≥4 位，保护 API 密钥与记忆）。
3. 手机扫设置面板里的二维码，打开管理页 → 「模型与 API」填入：
   - 大模型：DeepSeek API Key（platform.deepseek.com 申请）
   - ASR / TTS / 向量：硅基流动 API Key（cloud.siliconflow.cn 申请，一个 key 填三处）
   - 没有 embedding key 也能用（记忆召回退化为重要度排序）。
4. 每项配置旁点**「连通测试」**：绿色 ✓ 即链路通（会显示耗时）；红色 ✗ 会给出具体原因
   （401=key 无效、Failed to fetch=网络/跨域、超时=网络不通）。真机上密钥掩码显示不回传，
   测试前需重新粘贴完整 key。PC 模拟可直接测已保存的 key。
5. 「角色设定」可改大肥鱼的性格与说话方式；「试说一句」验证 TTS。

## 日常交互
- **语音**：说「大肥鱼」唤醒 → 听到提示后说话 → 停顿 0.7 秒自动识别回答。
  也可点屏幕下方麦克风按钮手动开始/结束。说话中点麦克风可打断。
- **触屏**：点她会摸头——蹦一下、扭扭身子，思考时歪头、说话时点头（当前混元 GLB
  模型为程序化肢体动画，无眨眼口型；想要真表情可换 VRM，见 docs/assets.md）。
  点窗户/床/玩偶/显示器/灯/地毯/收音机/绿植都有专属彩蛋台词。
- **她会自己活动**：待机时在房间里随机溜达（小碎步+转身+发呆东张西望，自动避开
  床/书桌/衣柜等家具）；语音唤醒或点麦克风后会小跑到镜头前左侧站定面向你，
  对话结束约 6 秒后继续自由活动。2.5D 降级模式下立绘同样会左右溜达、唤醒滑到左侧。
- **字幕**：设置里可开关。

## 城市天气与昼夜同步
- **时间自动同步现实**：窗外天色（日出/日落渐变、太阳月亮轨迹、夜晚星空与城市灯火）
  和房间光线都跟随本机时间变化，无需任何设置。傍晚暖橙色、深夜幽蓝、白天明亮。
- **设置城市**：设备 ⚙ 设置 → 「城市天气」搜索框输入城市名（如"广州"）→ 点候选项即保存；
  管理页「模型与 API」也有同样的「城市与天气」卡片。支持全国 340+ 城市即时搜索，
  国际城市走 Open-Meteo 补充搜索。清除按钮恢复默认雨景氛围。
- **左上角显示**：时钟旁会显示 `城市 天气图标 温度°`（如 `广州 ☁️ 17°`）。
- **窗外真实天气**：设为广州后，广州下雨窗外就下雨（雨丝+雨点粒子），下雪飘雪，
  雷阵雨偶有闪电，晴天蓝天白云，阴天灰蒙、雾天朦胧；台灯在阴雨天会自动更亮一点。
- **数据来源双通道**：国内城市走腾讯天气（wis.qq.com，免费无需 key，每 10 分钟刷新）；
  国际城市走 Open-Meteo。断网时保留上次天气状态不闪变。
- **2.5D 降级模式**同样支持：背景按半小时粒度重烘焙昼夜色调，雨雪粒子实时切换。

## 管理页（手机/电脑浏览器）
`http://<设备IP>:8080/#/admin`
- **状态与控制**：FPS/内存/运行时长、模拟唤醒、让她说话、停止、重载。
- **模型与 API**：服务商/模型/Base URL/密钥（掩码显示，重输才覆盖）、音色语速、
  唤醒词、记忆参数（topK/token 预算/衰减/归档/合并阈值）。
- **角色设定**：System Prompt 编辑 + 恢复默认 + 试音。
- **记忆宫殿**：房子剖面图，六个房间各存一类记忆；便签清晰度=记忆强度；
  拖拽换房间、拖进阁楼归档、点击编辑/置顶/删除。
- **记忆卡片**：列表 + 搜索 + 手动新建。
- **对话历史**：按会话折叠查看，可删除（不影响已生成记忆）。
- **固件更新**：上传新界面 zip 热更新，30 秒异常自动回滚。

## 记忆是怎么工作的
聊完一段（空闲 90 秒自动结束），大模型把内容整理成原子记忆卡片放进宫殿。
下次聊天只召回最相关的 ≤6 条（≤800 token），所以聊得越久她越懂你，
但上下文不会爆。常想起的记忆越来越清晰，久不提的慢慢淡忘进阁楼——
重要的事可以「置顶」，永不遗忘。每天凌晨 4 点自动做一次衰减/合并/归档。

## 常见问题
- **唤醒不灵**：检查设置里唤醒开关；真机需放入 KWS 模型（见 device-shell/README）；
  安静环境 1 米内最佳。PC 网页默认没有真唤醒引擎，用「模拟唤醒」按钮或点麦克风圆环；
  也可在 ⚙ 设置勾选「网页语音唤醒（实验）」后直接说「大肥鱼」（含同音容错如「大飞鱼」）。
  聆听提示会实时显示「听到：…」——有字说明麦克风正常，只是没命中唤醒词；一直没字
  则是浏览器语音服务问题。已加看门狗自动重启，长时间无响应会自行恢复聆听。
  该功能走浏览器 Web Speech API：Chrome 需连通 Google 语音服务（国内可能失败，
  连续失败会自动关闭并提示，建议改用 Edge）；不支持的浏览器开关置灰。
  对话/播报期间自动暂停聆听防止自激；开关只存在本浏览器，不随设备配置同步。
  实机唤醒由原生 sherpa-onnx KWS 负责（LX04 旧 WebView 不支持 Web Speech API）。
- **提示 Failed to fetch / 调用大模型失败**：多半不是 key 错。PC 网页模拟时浏览器直接调
  云端 API 会被跨域（CORS）拦截，现已内置开发代理自动转发，刷新页面即可；若仍失败，
  到管理页逐项点「连通测试」看具体错误：`HTTP 401` = key 无效或余额不足，
  `超时` = 本机到服务商网络不通。语音识别失败现在也会弹出具体错误而不再静默。- **用自建/中转 API 网关**：Base URL 直接填网关地址（如 `http://192.168.31.2:3065/v1`），
  模型名填网关支持的 ID（可访问 `<网关>/v1/models` 查看列表），服务商保持 deepseek
  （OpenAI 兼容格式即可）。PC 模拟会自动走代理避免跨域；若网关要求鉴权，API Key 填网关的 key。
- **声音僵硬像机器人 / 换活泼音色**：管理页 → 模型与 API → 语音合成 TTS → 服务商选
  **volcano（火山引擎豆包大模型音色）**，情感表现力远强于 CosyVoice2。
  注意：火山控制台已改版为「豆包语音」，不再有"领取音色包"入口——免费额度改为
  按模型「试用」（2 万字符 / 半年，试用期内全部音色可用）。新版开通步骤：
  1. 登录后打开新版控制台「开通管理」页（直达链接）：
     https://console.volcengine.com/speech/new/setting/activate?projectName=default
     （或 console.volcengine.com → 产品搜索「豆包语音」→ 左侧「开通管理」）；
  2. 模型列表找到**豆包语音合成模型 2.0** → 点【试用】领免费额度（2 万字符/半年，
     以页面显示为准；若只有「开通」按钮则为按量后付费，约 2.8 元/万字符，也很便宜）；
  3. 打开「API 管理」页创建并复制 **API Key**（直达链接）：
     https://console.volcengine.com/speech/new/setting/apikeys?projectName=default
     填到本项目 TTS 的「API Key」框；**「APP ID」留空**（新版不需要）、「模型」框保持
     `seed-tts-2.0`。注意左上角项目要与开通试用的项目一致（默认 default）；
  4. 「声音与唤醒」选音色：推荐**爽快思思 2.0**（活泼少女）或**撒娇学妹 2.0**（软糯），
     也可到控制台「音色库 → 探索」（console.volcengine.com/speech/new/voices）点音色右侧
     复制 Speaker ID，选 `_uranus_bigtts` 结尾的 2.0 音色填「自定义音色 ID」；
  5. 点「连通测试」变 ✓ 后保存，到「角色设定 → 试说一句」试听。
  报错速查：`quota exceeded … lifetime` = 试用额度用尽，需在控制台开通正式版或买资源包
  （按字符计费，很便宜）；`resource id / access denied` = 「模型」框 Resource-Id 与音色不匹配
  或该模型未开通试用。旧版「语音技术」应用（AppId + Access Token）仍兼容：填了 APP ID
  自动走旧 v1 接口，此时「模型」框填 cluster（volcano_tts / volcano_icl），
  `3001 音色未授权` = 该音色没领取或 cluster 不对。旧配置里的 1.0 音色 ID（moon/mars）
  在新版模式下会自动迁移为对应 2.0 音色（uranus）。
- **回答慢**：首句时延主要取决于 LLM/TTS 网络；状态页可看错误日志。
- **画面卡**：会自动降级 2.5D；也可在设置里手动切换。
- **忘了管理密码**：ADB 删除 config 文档重置（会丢 API 配置）：
  `adb shell "run-as com.xiaoai.shell rm databases/xiaoai.db"`（debug 包可用）。
